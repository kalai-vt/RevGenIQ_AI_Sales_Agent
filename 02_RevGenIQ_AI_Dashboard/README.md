# 02 — RevGenIQ AI Dashboard

Full-stack SaaS dashboard for managing AI agents, knowledge bases, leads, and analytics.

## Structure

```
02_RevGenIQ_AI_Dashboard/
├── frontend/    React 18 + Vite + TailwindCSS + Zustand + Recharts
├── backend/     FastAPI + SQLAlchemy + SQLite/PostgreSQL
```

## Quick Start

```bash
# Backend
cd backend
uvicorn main:app --reload --port 8000

# Frontend
cd frontend
npm install && npm run dev
```
